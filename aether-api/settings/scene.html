Scene

Declared Aether RNA properties for Scene.

Access through bpy.context.scene, when the required scene and object are available.

PropertyTypeDescription and declaration
aether_ao_strengthFloatPropertyExponent applied to the captured AO in every output that uses it (AO, ORM and mask maps, Bake AO): 1 is the capture, 2 squares it for deeper occlusion
default: 1.0 · min: 0.1
aether_auto_preview_delayFloatPropertySeconds to wait after the last edit before launching auto preview. Longer delays reduce workspace hitching while editing.
default: 0.75 · min: 0.05 · max: 10.0 · subtype: TIME
aether_auto_preview_enabledBoolPropertyAutomatically refresh fast preview after scene changes. Uses a guarded deferred update to avoid recursive refresh loops.
default: False
aether_bake_aoBoolPropertyInclude this map in the completed source-map bake set
default: True
aether_bake_cage_extrusion_scaleFloatPropertySelected-to-active ray start offset as a fraction of the combined source/target bounds diagonal.
default: 0.0025 · min: 0.0 · max: 0.25
aether_bake_curvatureBoolPropertyInclude this map in the completed source-map bake set
default: True
aether_bake_marginIntPropertyPadding in pixels around source-map UV islands; 16 by default
default: 16 · min: 0 · max: 128
aether_bake_material_idBoolPropertyInclude this map in the completed source-map bake set
default: True
aether_bake_max_ray_distance_scaleFloatPropertySelected-to-active maximum ray distance as a fraction of the combined source/target bounds diagonal. Lower values reduce projection bleed into unrelated outer surfaces.
default: 0.01 · min: 0.0 · max: 1.0
aether_bake_normalBoolPropertyInclude this map in the completed source-map bake set
default: True
aether_bake_normal_objBoolPropertyInclude this map in the completed source-map bake set
default: True
aether_bake_positionBoolPropertyInclude this map in the completed source-map bake set
default: True
aether_bake_resolutionEnumPropertySquare source-map image dimension in pixels
default: 2048 · choices: source expression [(str(x), f'{x}x{x}', '') for x in [512, 1024, 2048, 4096]]
aether_bake_samplesIntPropertyCycles sample count per source-map bake; 64 by default
default: 64 · min: 1 · max: 4096
aether_bake_uv_mapStringPropertyTarget UV layer for source baking; blank uses the active UV layer
default: Blender RNA default
aether_capture_samplesIntPropertyEEVEE samples for Base Color, Normal, Height, Roughness and the other maps (Per Map sampling). 32 differs from 128 only at anti-aliased edges
default: 32 · min: 1 · max: 4096
aether_capture_samples_aoIntPropertyEEVEE samples for the AO capture (Per Map sampling); AO keeps a little more grain than other maps at low counts
default: 64 · min: 1 · max: 4096
aether_capture_samplingEnumPropertyEEVEE samples for each capture
default: PER_MAP · choices: PER_MAP, SCENE
aether_curvature_contrastFloatPropertySigned-curvature contrast multiplier; 2 by default. Higher values emphasize convex and concave differences.
default: 2.0 · min: 0.0 · max: 8.0
aether_curvature_hard_weightFloatPropertyBalance between sharp edge highlights and broad cavity shading. 1.0 = only sharp edges, 0.0 = only cavity.
default: 0.65 · min: 0.0 · max: 1.0
aether_curvature_soft_radiusIntPropertyMesh smoothing iterations for the broad curvature component. Larger = broader, smoother cavity shading. Set to 0 to disable the soft pass entirely.
default: 4 · min: 0 · max: 64
aether_height_bumpFloatPropertyWeight of each material's shader relief in Height: Bump input x bump Distance x Bump Strength, in metres. 0 keeps Height geometry-only
default: 1.0 · min: 0.0
aether_height_maxFloatPropertyHeight written as 1 in Fixed Range mode, in metres along the capture camera's up axis (world Z for a top-down camera)
default: 0.05 · subtype: DISTANCE · unit: LENGTH
aether_height_minFloatPropertyHeight written as 0 in Fixed Range mode, in metres along the capture camera's up axis (world Z for a top-down camera)
default: 0.0 · subtype: DISTANCE · unit: LENGTH
aether_height_modeEnumPropertyHow metres of physical height map to the 0-1 Height image
default: AUTO · choices: AUTO, FIXED
aether_inpaint_distanceIntPropertyPixel distance for the compositor inpaint pass on the standard render path. Large values are much slower; 8-16 is usually enough.
default: 16 · min: 0 · max: 256
aether_last_source_map_directoryStringPropertyMost recently completed source-map set used by the node importer
subtype: DIR_PATH · default: Blender RNA default
aether_nearfield_slabsIntPropertyNumber of equal horizontal slabs between the lowest and highest construction point
default: 8 · min: 1 · max: 32
aether_preview_modeEnumPropertyWhether preview renders the selected output map or the full map set into the receiver material
default: ACTIVE_MAP · choices: ACTIVE_MAP, ALL_MAPS
aether_preview_resolution_percentageIntPropertyResolution percentage used by the fast EEVEE preview render. Lower values update faster.
default: 50 · min: 10 · max: 100 · subtype: PERCENTAGE
aether_region_indexIntPropertyActive entry in the region list
default: -1
aether_regionsCollectionPropertyNamed trim strips and decal pieces written to maps.json
default: Blender RNA default
aether_scatter_collectionPointerPropertyDirect child objects to instance on the Aether tile
default: Blender RNA default
aether_source_map_directoryStringPropertySource-map destination; blank uses the saved blend folder and target name
subtype: DIR_PATH · default: Blender RNA default
aether_source_objPointerPropertyOptional separate high-resolution mesh projected onto the source-bake target
default: Blender RNA default
aether_target_objPointerPropertyUV-mapped mesh receiving the source-map bake
default: Blender RNA default
aether_triplanar_spaceEnumPropertySource coordinate frame used by the triplanar conversion helper
default: AUTO · choices: AUTO, BAKED, OBJECT
aether_use_highpolyBoolPropertyProject the separate high-resolution source onto the UV-mapped receiver when enabled
default: False
custom_object_nameStringPropertyPrefix for output image names and generated material names
default: MyObject

default: Blender RNA default
export_output_directoryStringPropertyDestination for final PBR maps and the hidden preview cache; // is relative to the blend file
default: //exports/ · subtype: DIR_PATH
export_settingsPointerPropertySource mesh and UV selection for authoring-scene creation
default: Blender RNA default
