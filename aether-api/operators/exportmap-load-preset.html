bpy.ops.exportmap.load_preset(**properties)

Replace the scene map list with the chosen engine or workflow preset.

Context: A scene with Aether registered.
Limit: Replaces custom map entries; does not remove existing exported files. Packed and Height outputs are derived from separate captures at export, so they cost one render per distinct source map.
