exportmap.add_map

Add Map · current

bpy.ops.exportmap.add_map()

Add a Base Color entry and select it in the current scene map list.

Context: A scene with Aether registered.
Limit: Only changes the map list; no file is rendered.
Status: current

Operator properties

This operator declares no Aether-specific keyword properties. It may use scene, object, modifier, or editor settings instead; see its context and related settings below.

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

Scene

  • export_map_list — Ordered output map definitions for the active authoring scene
  • export_map_index — Zero-based active map index; -1 means the list is empty

MapExportItem

  • map_type — Type of map to export
  • map_name — Custom name for this output
