aether.normal_to_bump

Normal Map to Bump Height · current

bpy.ops.aether.normal_to_bump(convention=...)

Each ... is a placeholder for a value; see the properties below.

Integrate the active photo normal map into a height image and drive Bump with it.

Context: The active node of the active object's material is an Image Texture holding a tangent-space normal map that feeds the Aether master.
Limit: Writes <image>_height.png into //sources/; the blend must be saved. The normal image node is kept but unlinked from the master. The metre scale comes from the surface/UV area of the meshes using the material (otherwise the camera tile), divided by any Mapping repeat; adjust Distance or Strength by eye.
Status: current
