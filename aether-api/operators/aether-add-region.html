aether.add_region

Add Region · experimental

bpy.ops.aether.add_region(kind=..., margin_px=...)

Each ... is a placeholder for a value; see the properties below.

Add a named trim strip or decal region fitted to the selected objects.

Context: A scene with an orthographic camera; select the objects that make the strip or piece.
Effects: Appends one region to the scene list. Trim strips span the full width; a decal fits its pieces plus the margin.
Limit: Bounds are evaluated bounding boxes seen by the scene camera, not exact silhouettes. Nothing selected gives the whole capture.
Status: experimental

Operator properties

PropertyTypeDescription and declaration
kindEnumPropertyTrim strips repeat along U; decals are separate pieces
default: DECAL · choices: TRIM, DECAL
margin_pxIntPropertyTexels added around the fitted bounds
default: 4 · min: 0 · max: 256

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

Scene

  • aether_regions — Named trim strips and decal pieces written to maps.json
  • aether_region_index — Active entry in the region list

AetherRegion

  • kind — Trim strips repeat along U; decals are separate pieces
  • name — Name written to maps.json
  • uv_min — Lower-left corner in capture UV (origin bottom-left)
  • uv_max — Upper-right corner in capture UV (origin bottom-left)
