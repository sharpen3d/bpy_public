Apply Settings for Selected Map · current

bpy.ops.exportmap.apply_map_settings(**properties)

Select a map, route its authoring output and configure its image settings.

Context: An Aether scene and a valid zero-based index.
Limit: Changes the shared output route and scene render settings; does not render. Derived outputs (packed, DirectX, inverted) show their first source capture; Height shows raw metres, so use Render Fast Preview for the normalized image.
Status: current
