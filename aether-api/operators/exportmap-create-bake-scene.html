exportmap.create_bake_scene

Create Bake Scene · current

bpy.ops.exportmap.create_bake_scene()

Create an Aether authoring scene with a UV canvas, preview object and orthographic camera.

Context: Set scene.export_settings.source_object to a mesh with a UV map.
Limit: Switches the window scene/workspace and creates datablocks. The selected source remains the live geometry input.
Status: current

Operator properties

This operator declares no Aether-specific keyword properties. It may use scene, object, modifier, or editor settings instead; see its context and related settings below.

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

MapExportSettings

  • source_object — Mesh whose evaluated geometry and selected UV map feed the authoring canvas
  • uv_map — UV layer sampled by the authoring canvas; NONE means the target has no UV layers

Scene

  • export_settings — Source mesh and UV selection for authoring-scene creation
  • custom_object_name — Prefix for output image names and generated material names
  • export_output_directory — Destination for final PBR maps and the hidden preview cache; // is relative to the blend file
