aether.height_use_measured

Use Measured Range · current

bpy.ops.aether.height_use_measured(match_target=...)

Each ... is a placeholder for a value; see the properties below.

Copy the last measured Z range into the remap of the selected layers.

Context: Selected objects that were part of a Height capture.
Limit: Measured values come from the last export or preview that rendered Height. Sets From to Manual with the measured range and leaves To unchanged unless Match is enabled.
Status: current

Operator properties

PropertyTypeDescription and declaration
match_targetBoolPropertyAlso set To Min/Max to the measured range (identity remap)
default: False

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

Object

  • aether_height — Per-layer Height remap: own Z range to target metres

LayerHeightSettings

  • measured_min — Lowest visible Z of this layer in the last Height capture
  • measured_max — Highest visible Z of this layer in the last Height capture
  • target_min — Height written for the bottom of this layer, in metres
  • target_max — Height written for the top of this layer, in metres; a larger span than the source exaggerates it
