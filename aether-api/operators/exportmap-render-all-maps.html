exportmap.render_all_maps

Render All Maps · current

bpy.ops.exportmap.render_all_maps()

Render the complete output map list and assign the resulting PBR material to the preview.

Context: An Aether authoring scene with a camera, output folder and supported material routes.
Limit: Runs synchronously at full resolution, one EEVEE capture per direct map and per source of derived maps (Height, packed, DirectX, inverted). Writes <name>_maps.json with encodings and the height range in metres. File publication is not undone by Blender Undo. Restores scoped output and layer state on failure.
Status: current

Operator properties

This operator declares no Aether-specific keyword properties. It may use scene, object, modifier, or editor settings instead; see its context and related settings below.

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

Scene

  • export_map_list — Ordered output map definitions for the active authoring scene
  • export_output_directory — Destination for final PBR maps and the hidden preview cache; // is relative to the blend file
  • custom_object_name — Prefix for output image names and generated material names
  • delimiter — Text joining the object prefix and map name in exported filenames
  • aether_capture_sampling — EEVEE samples for each capture
  • aether_capture_samples — EEVEE samples for Base Color, Normal, Height, Roughness and the other maps (Per Map sampling). 32 differs from 128 only at anti-aliased edges
  • aether_capture_samples_ao — EEVEE samples for the AO capture (Per Map sampling); AO keeps a little more grain than other maps at low counts
  • aether_height_mode — How metres of physical height map to the 0-1 Height image
  • aether_height_min — Height written as 0 in Fixed Range mode, in metres along the capture camera's up axis (world Z for a top-down camera)
  • aether_height_max — Height written as 1 in Fixed Range mode, in metres along the capture camera's up axis (world Z for a top-down camera)
  • aether_height_bump — Weight of each material's shader relief in Height: Bump input x bump Distance x Bump Strength, in metres. 0 keeps Height geometry-only
  • aether_ao_strength — Exponent applied to the captured AO in every output that uses it (AO, ORM and mask maps, Bake AO): 1 is the capture, 2 squares it for deeper occlusion

MapExportItem

  • map_type — Type of map to export
  • map_name — Custom name for this output
  • bit_depth — Bit depth per channel
  • color_space — Interpretation of the exported map; data roles remain linear regardless of display appearance
  • channel_format — Channels written to the image; single-channel EXR uses RGB storage for compatibility
  • normal_convention — Tangent-normal green channel: OpenGL is +Y up (Blender, glTF, Unity, Plush); DirectX flips green (Unreal, Substance DirectX)
  • bake_ao — Multiply this Base Color by the AO map (after AO Strength), in linear light: 0 leaves color unchanged, 1 applies full AO. For engines or looks that need occlusion in the albedo
  • pack_rgb — What fills the red, green and blue channels of a packed map
  • pack_r — Scalar map written to red
  • pack_g — Scalar map written to green
  • pack_b — Scalar map written to blue
  • pack_a — Scalar map written to alpha; None writes no alpha channel
