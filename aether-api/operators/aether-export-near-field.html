aether.export_near_field

Export Near-Field Slabs · experimental

bpy.ops.aether.export_near_field(**properties)

Capture the construction in horizontal slabs for near-field relief in an engine.

Context: A working project with an orthographic scene camera and an export folder.
Limit: Writes <export folder>/nearfield/: per slab 16-bit PNGs (Base Color with coverage alpha, Normal, Roughness, Metallic, AO, Height over the slab's range) and <name>_nearfield.json. Each slab is a clip-range capture, so only geometry within it is seen; relief that exists only in the shader appears in normals and Height, never in coverage. AO lacks occlusion from geometry outside the slab. Experimental: no engine consumes it yet.
Status: experimental
