aether.export_near_field

Export Near-Field Slabs · experimental

bpy.ops.aether.export_near_field()

Capture the construction in horizontal slabs for near-field relief in an engine.

Context: A working project with an orthographic scene camera and an export folder.
Limit: Writes <export folder>/nearfield/: per slab 16-bit PNGs (Base Color with coverage alpha, Normal, Roughness, Metallic, AO, Height over the slab's range) and <name>_nearfield.json. Each slab is a clip-range capture, so only geometry within it is seen; relief that exists only in the shader appears in normals and Height, never in coverage. AO lacks occlusion from geometry outside the slab. Experimental: the generated relief pack is consumed by Plush’s near-field relief path.
Status: experimental

Operator properties

This operator declares no Aether-specific keyword properties. It may use scene, object, modifier, or editor settings instead; see its context and related settings below.

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

Scene

  • export_output_directory — Destination for final PBR maps and the hidden preview cache; // is relative to the blend file
  • aether_nearfield_slabs — Number of equal horizontal slabs between the lowest and highest construction point
  • aether_ao_strength — Exponent applied to the captured AO in every output that uses it (AO, ORM and mask maps, Bake AO): 1 is the capture, 2 squares it for deeper occlusion
  • aether_height_bump — Weight of each material's shader relief in Height: Bump input x bump Distance x Bump Strength, in metres. 0 keeps Height geometry-only
  • export_map_list — Ordered output map definitions for the active authoring scene
