aether.preview_layer_result

Preview Layer Result · current

bpy.ops.aether.preview_layer_result()

Render the full map set into the 3D PBR preview with layer contributions applied.

Context: An Aether authoring scene with output maps and a preview object.
Limit: Uses the file-backed preview cache and synchronous rendering; Edit Layers returns the authoring route.
Status: current

Operator properties

This operator declares no Aether-specific keyword properties. It may use scene, object, modifier, or editor settings instead; see its context and related settings below.

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

Scene

  • aether_preview_mode — Whether preview renders the selected output map or the full map set into the receiver material
  • aether_preview_resolution_percentage — Resolution percentage used by the fast EEVEE preview render. Lower values update faster.
  • export_map_list — Ordered output map definitions for the active authoring scene

LayerSettings

  • enabled — Apply this object map participation and AO casting controls
  • base_color — Include this geometry in the base color output
  • normal — Include this geometry in the normal output
  • roughness — Include this geometry in the roughness output
  • metallic — Include this geometry in the metallic output
  • ao — Show this surface in the AO map; independent of Cast AO
  • opacity — Include this geometry in the opacity output
  • cast_ao — Allow this geometry to occlude other surfaces in the AO map
