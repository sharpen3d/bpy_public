aether.repeat_geometry

Repeat Geometry for Tile · current

bpy.ops.aether.repeat_geometry()

Repeat the selected layer result at tile offsets after its existing modifiers.

Context: Selected mesh or curve objects in Object Mode.
Limit: Copies the evaluated seeded result; oversized features need a sufficient Repeat Radius.
Status: current

Operator properties

This operator declares no Aether-specific keyword properties. It may use scene, object, modifier, or editor settings instead; see its context and related settings below.

Related settings

Other context, including selection and editor state, is described above. Browse the RNA settings in the sidebar for scene and object controls.

Resulting Geometry Nodes modifier inputs

These are editable inputs on the created modifier, not keyword arguments to the operator.
