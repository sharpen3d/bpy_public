aether.scatter_collection

Scatter Collection as Tile Layer · current

bpy.ops.aether.scatter_collection(collection_name=...)

Each ... is a placeholder for a value; see the properties below.

Create an editable seeded collection scatter and repeat its result across the tile.

Context: An Aether authoring scene in Object Mode and a nonempty source collection.
Limit: Direct children use reset transforms and local geometry; does not hide originals, convert materials or resolve collisions. Canvas is XY from zero; assets should use Aether materials.
Status: current

Operator properties

PropertyTypeDescription and declaration
collection_nameStringPropertySource collection name, or use the scene picker when empty
default: Blender RNA default
