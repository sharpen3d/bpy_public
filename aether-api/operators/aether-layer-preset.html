aether.layer_preset

Set Layer Contributions · current

bpy.ops.aether.layer_preset(preset=...)

Each ... is a placeholder for a value; see the properties below.

Set output participation and AO casting on selected mesh layers.

Context: Selected meshes in Object Mode.
Limit: Normal Only also disables AO casting. Individual checkboxes edit the active object, while the preset affects all selected meshes.
Status: current

Operator properties

PropertyTypeDescription and declaration
presetEnumPropertyALL, NORMAL_ONLY or NO_AO participation for every selected mesh
default: Blender RNA default · choices: ALL, NORMAL_ONLY, NO_AO

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

Object

  • aether_layer — Per-object output-map participation and dedicated AO casting controls

LayerSettings

  • enabled — Apply this object map participation and AO casting controls
  • base_color — Include this geometry in the base color output
  • normal — Include this geometry in the normal output
  • roughness — Include this geometry in the roughness output
  • metallic — Include this geometry in the metallic output
  • ao — Show this surface in the AO map; independent of Cast AO
  • opacity — Include this geometry in the opacity output
  • cast_ao — Allow this geometry to occlude other surfaces in the AO map
