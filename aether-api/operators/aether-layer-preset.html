bpy.ops.aether.layer_preset(**properties)

Set output participation and AO casting on selected mesh layers.

Context: Selected meshes in Object Mode.
Limit: Normal Only also disables AO casting. Individual checkboxes edit the active object, while the preset affects all selected meshes.
