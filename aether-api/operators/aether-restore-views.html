aether.restore_views

bpy.ops.aether.restore_views(**properties)

Restore the authoring camera view and frame the evaluated preview object.

Context: An Aether scene with a window, authoring camera and .stx_preview object.
Effects: Switches this window to the Aether workspace and changes its view framing.
Limit: Does not isolate collections or enable live capture; local-view filtering remains unchanged.

Properties

No operator properties documented.
