aether.collect_project_files

Make Project Self-Contained · current

bpy.ops.aether.collect_project_files(**properties)

Make the saved project folder self-contained: unpack images and reference them relatively.

Context: A saved blend; its folder is the project folder.
Limit: Writes packed or external images into //sources/ (identical files are reused) and rewrites image paths; existing files are never overwritten. Image sequences, movies and UDIM tiles are reported and left unchanged. Save the blend afterwards to keep the new references. File writes are not undone by Blender Undo.
Status: current

Properties

No operator properties documented.
