exportmap.render_active_map_preview

Render Fast Preview · current

bpy.ops.exportmap.render_active_map_preview()

Refresh the cached 3D preview using the selected preview mode and resolution.

Context: An Aether scene with a .stx_preview object and output maps.
Limit: Active Map shows one output; All Maps renders the full stack. Uses file-backed cache images and can block the interface.
Status: current

Operator properties

This operator declares no Aether-specific keyword properties. It may use scene, object, modifier, or editor settings instead; see its context and related settings below.

Related settings

These are configured on the scene or object; they are not passed to the operator as keyword arguments.

Scene

  • aether_preview_mode — Whether preview renders the selected output map or the full map set into the receiver material
  • aether_preview_resolution_percentage — Resolution percentage used by the fast EEVEE preview render. Lower values update faster.
  • aether_inpaint_distance — Pixel distance for the compositor inpaint pass on the standard render path. Large values are much slower; 8-16 is usually enough.
  • export_map_list — Ordered output map definitions for the active authoring scene
  • export_map_index — Zero-based active map index; -1 means the list is empty
