Reference for Aether’s Blender operators and RNA settings, generated from the add-on’s operator docstrings and property descriptions.

Enable Aether before calling bpy.ops. Operators can require a particular scene, selection, mode or editor context; check each entry. File writes are outside Blender Undo. Internal Python helpers are not a supported public API.
