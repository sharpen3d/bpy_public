What I’m working on

Sprite Toolkit is the current home for my Blender 2D tools, previously shown here as Pixels and 2D Tools. I’m continuing the work on image and layer editing, pixel alignment, and getting useful 2D output from a Blender scene.

The workflow

The earlier tools manage image planes, pivots, orthographic cameras, and the relationship between scene units and output pixels. The current code expands that work with layers, masks, effects, compositions, and export tools.

Development status

This is an active personal tool. The public repository still needs updating, so the media here shows the earlier workflow rather than a current release. I’ll add the updated source when it is ready to share.
