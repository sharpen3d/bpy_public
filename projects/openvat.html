Project notes

Independent tool

Why I made it

I wanted an understandable, open-source route from Blender’s procedural deformation to a game engine. OpenVAT captures the motion in textures, then a shader uses that data to move the mesh on the GPU.

My work

I built the Blender tool and the Unity and Unreal integrations. Geometry Nodes drives the baking itself; Python handles the interface and the surrounding workflow. Working on the engine side let me explore how each renderer exposes its vertex stage, and where precision, normals, and import settings get in the way.

Release and community

OpenVAT is free and open source, with walkthroughs and engine examples on its own site. AntzGames also built a separate Godot integration. The links below cover the current tool, documentation, and source.
