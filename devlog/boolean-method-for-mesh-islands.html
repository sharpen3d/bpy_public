Boolean method for 'mesh islands'

Simple graph reference for creating smooth noise-based mesh islands via geometry nodes.

The goal

Quick experiment, useful for reference. This method could be used as example of curve generation approaches over voxel-like exclusion approaches for creating isolation in mesh via nodes. This may be used in something like sprite-outline behavior or combined with 2D SDF to prove useful for cutout meshing behavior.
